# 3스테이지 가지 타기

`Stage_02_Mazes`의 다음 씬은 `Stage_03_BranchRide`입니다. 기존 `Stage_03_Altar` 씬은 보존합니다.

- 두 플레이어가 시작 부적 근처에서 각각 E를 눌러 탑승하면 자동 출발합니다.
- 수액 R을 T1~T4 과녁에 주입하면 해당 가지가 회전하여 다음 구간이 열립니다. 한 번의 연속 분사에는 한 번만 반응합니다.
- 부적 위의 잎 소켓에 나뭇잎을 설치하면 멈추고, 잎을 회수하면 다시 이동합니다.
- 두 번의 하강 구간에 돌이 주기적으로 떨어집니다. 돌이 부적에 닿으면 두 탑승자와 부적, 과녁 및 가지가 시작 상태로 돌아갑니다. 돌이 잎에 닿으면 잎이 회수됩니다.
- 경로 속도, 과녁 충전량, 돌 주기, 탑승 거리 등은 씬의 `BranchRideFlow`에서 조정합니다. 장면 생성기는 `Herbalist/Stages/Create Branch Ride Stage`입니다.
