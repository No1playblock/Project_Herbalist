# develop_stage1 환경 리소스 갱신

## 원본과 복제 씬

- 브랜치: `develop_stage1`, 커밋 `d00e43e6fadfa94b257db1dc69d3372166aab483`.
- 원본 씬: `Stage_01_ModelingReference_CharacterBranch.unity`.
- 복제본: `Assets/_Project/Scenes/Stages/Stage_01/Stage_01_ModelingReference_CharacterBranch_DevelopStage1_20261108_Reference.unity`.
- 복제본의 씬 본문은 브랜치 원본과 바이트 단위로 동일하다. 새 씬 GUID를 사용하며 기존 메인 씬과 빌드 경로는 유지한다.

## 리소스 반영

- GUID로 현재 리소스와 대조하여 기존 파일 6개를 갱신하고 새 파일 39개를 추가했다. Git LFS 원본 데이터를 받아 사용했다.
- 새 FBX 7개: 동굴 바위, 절벽 1·2·3, 계단, 폭포 바위 2종. 각 FBX의 재질과 알베도·노멀·금속/매끄러움 텍스처를 함께 가져왔다.
- 기존 파일: 선낭나무 FBX, 나무 재질, 가지 재질·알베도·노멀, PolyOne 바위 공용 컬러 텍스처.
- 새 파일은 `Assets/_Project/Art/Environments/Stage_01/DevelopStage1Import_20261108`에 모델·재질·텍스처로 나눴다. 이미 같은 GUID가 있는 파일은 기존 경로를 사용했다.
- 안개 재질과 지형 데이터는 이번 나무·바위 리소스 갱신 대상에서 제외했다.

## 기존 씬의 나무 좌표 호환

새 나무 FBX는 메시가 `tree_low`에서 `seonag_tree`로 바뀌고 로컬 좌표 단위와 축도 달라졌다. 이전 메시 참조는 새 FBX에 존재하지 않아 단순 파일 교체만으로는 기존 씬의 나무와 충돌체가 사라진다.

- 원본 새 FBX는 수정하지 않고 복제 씬에서 그대로 사용한다.
- 기존 씬에는 새 FBX의 정점·UV·노멀·접선을 기존 나무 로컬 좌표로 변환한 `Models/SeonangTree/MS_SeonangTree_PlayableCompatibility.asset`을 연결했다.
- 변환은 기존 나무의 월드 행렬 역행렬과 원본 복제 씬 나무의 회전·크기를 사용한다. 이동은 기존 나무의 피벗 위치를 유지한다.
- 기존 프리팹의 MeshFilter와 메인·이전 CharacterBranch 씬의 나무 MeshCollider만 새 메시로 연결했다. 씬 파일에서는 해당 MeshCollider 블록 외의 모든 직렬화 데이터를 보존했다. 오브젝트 위치·회전·크기·활성 상태와 기믹 연결은 변경하지 않았다.
- 메인에서 사용하던 나무 재질에도 새 원본 재질의 텍스처·속성을 반영했다. 셰이더의 `_DETAIL_SCALED` 키워드는 Unity의 재질 검증 과정에서 정규화되었다.

정점 수는 12,436 → 12,468이다. 보정 메시의 로컬 경계 크기 차이는 이전 대비 X -0.001127, Y +0.000001, Z +0.000779로 기존 형상 범위를 유지한다.

## 검사 범위

- 복제 씬 본문과 원본 동일성, 새 리소스 GUID 및 LFS 내용, 모델·재질 임포트를 확인했다.
- 선낭나무의 시각 메시와 충돌체가 같은 보정 메시를 참조하는 것을 확인했다.
- 원본 및 기존 씬에는 이미 존재하던 누락된 가지 시각화·수련 재질과 나무 프리팹 참조가 있다. 복제 씬 원본을 유지하기 위해 이번 작업에서 해당 별도 문제는 변경하지 않았다.
- 새 절벽·동굴·폭포 바위의 배치는 복제 씬에 포함된다. 플레이용 씬을 새 배치로 교체하지 않았다. 공용 나무·바위 리소스 변경은 기존 씬에도 반영된다.
- Reload 확인 후 최종 화면·플레이 검사를 완료했다. 새 나무 렌더링과 텍스처 연결, 복제 씬의 새 바위·계단 FBX 7종의 재질 누락 0건을 확인했다.
- 실제 플레이에서 프레임 진행(155 프레임), 플레이어 2명, 시각 메시와 동일한 나무 충돌체를 확인했다. 나무 표면의 41개 샘플 레이캐스트가 모두 적중했고 Console 오류는 0건이었다. 화면은 `Temp/Stage1Environment_MainTree.png`, 플레이 검사 결과는 `Temp/Stage1EnvironmentActualPlay.json`에 기록했다.
