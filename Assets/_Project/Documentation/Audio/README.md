## 씬과 생명주기

11개 씬과 16개 관련 프리팹에 작성했다. 씬마다 GameAudio와 24개 AudioSource가 있고, 플레이어/지속음 오브젝트는 3개씩 작성된 채널을 가진다. 런타임에는 오디오 오브젝트나 UI를 생성하지 않는다. 원샷은 씬 풀에서 마무리되어 잎/물 오브젝트 제거 시 꼬리가 잘리지 않으며, 루프는 해당 오브젝트 비활성화/상태 종료 시 멈춘다. 채널이 모두 차면 새 소리를 생략하며 기존 루프를 강제로 끊지 않는다.

같은 효과음도 플레이어·오브젝트별 쿨다운을 적용해 두 명이 동시에 행동할 때 서로의 소리를 차단하지 않는다. 기존 전체 오디오 볼륨 설정을 따른다. 일시정지 시 게임 효과음을 Pause/UnPause하며 UI는 사용할 수 있다. 숲 배경음은 스트리밍, 월드 음원은 mono, 짧은 효과음은 미리 디코드하도록 임포트했다.

걷기는 현재 `footstepSoundId=10`으로 모든 바닥에서 흙 발소리를 사용한다. `fallingWindEnabled=false`로 공중 낙하 바람은 재생하지 않는다. 두 설정은 카탈로그에서 조정한다. `SfxSurface`는 흙/목재 착지음 구분에 계속 사용한다. 모든 충돌체의 설정·위치와 기존 게임플레이 컴포넌트 직렬화 값은 작성 전후 비교로 보존했다.

## 재작성과 검사

- `Tools > Herbalist > Audio > Apply SFX Catalog And Presenters`: 전체 초기 설정 재작성. **현재 카탈로그의 수동 튜닝도 초기값으로 되돌리므로** 단순 음원 교체에는 이 메뉴를 누르지 않고 에셋을 편집한다.
- `Tools > Herbalist > Audio > Validate SFX Assets`: 카탈로그/씬/프리팹 참조와 클립·루프 규칙 검사. 씬을 저장하고 Edit 모드에서 실행한다.
- `Herbalist.Editor.SfxIntegrationChecks.ValidatePlayback()`: Play 모드에서 전체 음원 재생, 루프, Pause/UnPause, UI, 소유자별 쿨다운, 비활성화 정리와 잎/물 상태 전환을 검사한다. 격리된 테스트 오브젝트를 만들고 제거하며 씬에 저장하지 않는다.

기존 개발용 `Development/Stage1_ModelingTest`에는 Fine_Tree 프리팹 3종 누락 경고가 있다. SFX 작업과 별개이며 해당 원본을 복원하지 않았다. 실제 2인 Host/Client 장시간 청취와 최종 음량 감수는 이번 자동 검사에 포함되지 않는다.
