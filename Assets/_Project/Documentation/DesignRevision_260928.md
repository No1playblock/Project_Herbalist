# 260928 기획 개편 검토

상태: 기획서 읽기 및 현재 구현 비교 완료. 구조·입력·제단 위치 선택 대기. 이 문서는 구현 완료 보고가 아니다.

기준: `서낭당_레벨_기획서_260928.pdf` (35쪽). 문서에 남아 있는 이전 스테이지 번호와 상향 진행 설명은 최신 하향 진행 설명과 구분한다.

## 추천 구성

기존 기능을 재사용하고 진행 흐름은 세 씬으로 분리한다.

1. 외부: 약초 채집·제조·복용 → 무당나무 외벽 상승 → 두 명 상단 도착 → 수액 주입으로 입구 개방 → 두 명 내부 진입.
2. 미로: 각자 뗏목에 진입 → 같은 두 뗏목으로 세 미로를 차례로 하강 → 마지막 미로 완료 시 다음 씬 이동.
3. 제단: 수액으로 석판 회전 → 나뭇잎으로 각도 고정 → 문양 정렬 → 계단 변형 → 두 명 탈출.

입력, CharacterController 이동, 능력, 표현, Fusion 어댑터 분리는 유지한다. 천·점프대·상단 입구·제단은 배치 가능한 독립 컴포넌트로 만들고, 씬 진행 담당자는 완료 상태만 조합한다. 이후 기믹 배치나 난이도 변경은 설정 에셋과 인스펙터로 처리한다.

## 변경 범위

| 구간 | 현재 구현 | 새 기획 |
| --- | --- | --- |
| 나뭇잎 | 비행/설치/회수 합산 3개, 수명, 한도 도달 시 회수 후 재입력 | 설치 3개, 수명 없음, 추가 사용 시 오래된 설치물 회수와 새 설치 진행 |
| 나뭇잎 사거리 | 카메라 레이 거리 중심 | 플레이어 기준 약 키의 3배, 설치 가능 대상만 허용, 멀면 캐릭터별 자막 |
| 수액 | 나무에서 추출 후 호스/설치 | 외부 기믹에 능력을 사용하여 생성·주입, 미로에서는 시작 수액 직접 조종 |
| 점프대 | 고정 주입구/나뭇잎 소켓, 두 명 자동 발사, 지정 착지점 | 대칭 구멍 두 개, 반대 구멍 분출, 3초 주입, 발사 순간 점프와 개별 공중 조작 |
| 매듭 천 | 없음 | E로 잡기/놓기, 첫 탑승자가 흔들기, 둘이 잡기 가능, 최대 30도·복귀·장애물 충돌 |
| 낙하 복구 | 구간별 지정 복구 위치 | 마지막 일반 발판/점프대 착지 위치, 나뭇잎과 천 제외, 파트너/설치물 유지 |
| 외부 입구 | 두 약제 제조·복용으로 개방 | 약제 후 외벽 진행, 두 명 상단 도착과 수액 주입으로 개방 |
| 미로 이동 | 구간마다 별도 리프트 탑승, 최종 두 명 출구 | 같은 두 뗏목 지속 사용, 미로 해결 시 자동 하강, 세 번째 해결로 클리어 |
| 미로 화면 | 일반 카메라·화면 전환 가능 | 개인 화면 고정, 앞/뒤 정보 구분, 전환 제한 |
| 제단 | 도착 플레이스홀더 | 고정 상단과 회전 석판 3개, 수액 시작·나뭇잎 정지, 정렬 후 계단 |

미로 도면 세 개는 기존 도면과 이미지가 동일하다. 도면/그래프 데이터는 재사용하고 진행·카메라·뗏목을 변경한다.

## 선택 항목

- 씬: A = 세 씬 분리 및 기존 기능 재사용 (추천), B = 한 씬에서 구간 활성화.
- 입력: A = R을 대상별 능력 사용으로 통일하고 나뭇잎 형태는 대상이 결정 (추천), B = 기존 R 모드 전환/좌클릭 사용 유지.
- 제단: A = 내부 하강 끝의 3스테이지 (추천), B = 별도 상승 경로를 유지해 최상층 배치. 전체 흐름과 제단 절의 예전 설명이 충돌하므로 선택이 필요하다.

## 승인 후 구현 순서

1. 선택된 진행/입력 규칙을 설정 에셋과 문서에 반영한다. 기존 씬·데이터는 개편 검증 전 보존한다.
2. 나뭇잎 대상 판정·거리·수명·한도 교체, 외부 수액 주입과 점프대를 수정한다.
3. 천 잡기/흔들기와 착지 체크포인트를 구현하고 외부 상승 경로를 구성한다.
4. 상단 주입/입구와 능력·역할을 보존하는 씬 전환을 연결한다.
5. 동일한 두 뗏목의 자동 하강, 개인 화면 제한, 미로별 재시도를 적용한다.
6. 회전 제단·각도 정지·정렬·계단 변형·협동 탈출을 구현한다.
7. 사전 배치 UGUI 안내·자막을 연결하고 솔로 디버그와 Fusion Host/Client를 검증한다.

## 검증 기준

- 약제는 캐릭터와 독립적으로 한 번만 선택되며 씬 이동 후 보존된다.
- 사거리 밖 나뭇잎 사용은 개수/상태를 소비하지 않는다. 네 번째 설치 교체는 Host/Client 모두 같은 오래된 나뭇잎을 회수한다.
- 점프대 두 구멍 모두 역할을 바꿔 사용할 수 있고, 빈 반대 구멍에도 수액 분출이 표현된다. 공중 이동은 각 플레이어 입력을 따른다.
- 천의 최초 조종자, 동승/해제, 장애물 충돌이 Host에서 검증되고 복제된다.
- 개인 낙하가 상대 진행이나 설치물을 초기화하지 않는다.
- 외부 입구는 상단 도착/주입/두 명 진입의 조건을 순서대로 검증한다.
- 미로 조종 중 플레이어 이동은 잠기고, 개인 화면 제한은 해당 씬에서만 적용된다. 실패 시 현재 미로만 복구한다.
- 뗏목이 세 미로 사이에서 유지되고 세 번째 해결 후 중복 없이 전환한다.
- 제단의 잘못된 각도 고정도 가능하며 회수 시 회전이 재개된다. 올바른 정렬만 계단 변형을 시작한다.
- 모든 UGUI가 재생 전에 씬/프리팹에 존재하며 런타임 생성 코드가 없다.
