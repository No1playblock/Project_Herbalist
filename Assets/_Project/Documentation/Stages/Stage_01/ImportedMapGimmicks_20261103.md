## 조정과 구현 범위

- `SO_ImportedStageOneRules` / `SO_ImportedStageOneLeaf`가 새 씬 전용 설정이다. 다른 씬의 잎 유지 규칙은 변경하지 않았다.
- 성장·복원 시간, 성장 배율, 장애물 이동, 가지 회전/이동량, 천 1회 이용·말림 시간, 잎 회수 지연은 에셋 또는 씬 Inspector에 직렬화되어 있다.
- Host가 주입·해제·발사와 기믹 상태를 결정한다. 새 기믹의 진행량/완료 상태, 천 사용 여부/말림 상태는 Fusion 상태이며 클라이언트는 이를 표시한다. 기존 Fusion 및 CharacterController 구조를 재사용했다.
- 채집 약초 두 개는 새 맵의 실제 개별 꽃/허브 모델에 상호작용점을 연결했다. 배경의 전체 꽃 무리를 한 번에 채집하는 연결은 사용하지 않는다. 오프라인 직접 Play도 기존 네트워크 시작점에서 시작한다. 원래 편집된 플레이어 Transform은 이동하지 않았다.
- 새 UGUI를 런타임에 생성하지 않는다. 기존 HUD, 도움말, 능력 표시를 재사용한다. 솔로 테스트용 스테이지 단축키는 씬에 미리 배치했다.
- `StageOneDocumentAuthoring.Apply()`는 한 번만 적용하는 편집 도구이며 이미 연결된 씬에 재실행하지 않는다. 이후에는 씬/Inspector에서 편집한다.
