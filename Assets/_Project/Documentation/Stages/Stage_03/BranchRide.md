## 조작과 규칙

- 각 플레이어가 시작 부적 근처에서 E로 탑승한다. 두 명이 모두 탑승하면 자동 출발한다. 한 명은 기다리고, 탑승 후 임의 하차/일반 이동은 잠긴다. 카메라와 능력은 유지한다.
- 수액: 과녁을 조준하여 R을 유지한다. 한 번의 연속 분사에는 한 번만 작동한다. 분사를 끊고 재무장 시간이 지난 뒤 다시 맞히면 반대 자세로 회전한다. 부분 충전은 긴 분사 중단 후 초기화한다.
- 나뭇잎: R로 가지 표면의 원하는 위치에 설치한다. 부적이 설치 지점에 접근하면 정지한다. 좌클릭으로 가장 오래된 설치 잎을 회수하면 이동을 재개한다. 부적 위 고정 잎 소켓은 사용하지 않는다.
- 과녁을 맞히기 전 A 자세에서는 막다른 갈래, 맞힌 뒤 B 자세에서는 다음 구간으로 이어진다. 부적이 분기점에 도달했을 때 회전 중인 가지의 입구가 연결되어 있지 않으면 추락한다.
- 의도된 두 낙하는 중력을 따르는 하강 궤적으로 다음 가지에 착지한다.
- 돌은 위에서 낙하 → 가지를 따라 구르기 → 아래로 추락 → 재생성 대기(기본 3초)를 반복한다. 이동 거리/속도/시간차는 개별 Inspector 설정이다.
- 돌과 설치 잎의 접촉은 잎만 회수한다. 돌은 계속 진행하므로 잎이 부적을 보호하지 않는다. 부적과 충돌하면 실패한다. 저프레임에서도 이동 구간을 따라 접촉을 검사한다.
- 실패하면 탑승자 운송을 해제하고 둘을 시작 위치로 이동시킨다. 부적, 과녁/가지, 설치 잎, 수액, 돌 주기를 초기화한다. 체크포인트는 없다.
- 최하단에 도착하면 두 플레이어의 운송을 해제하고 지정된 하차 위치에 내려준다. 부적은 정지하고 완료 UGUI를 표시한다.
- 게임 일시정지 시 가지 회전, 부적 이동, 낙하 및 돌 주기가 멈춘다.

## 코드 책임과 네트워크

- `BranchRideFlow`: Host 판정, 진행 구간/상태, 두 탑승자, 접속·돌 충돌, 실패/완료와 기존 모터 운송 연결.
- `BranchRideCarrier`: 트랙을 따르는 이동/낙하/잎 정지 계산. 네트워크나 입력을 소유하지 않는다.
- `BranchRideTrack`: 경로 노드/거리 샘플링과 Inspector에 배치한 다음 가지 참조(`_exits`). 배열의 다음 번호로 이동하지 않고 실제 맞닿는 출구를 선택한다. 마지막 구간만 `_isFinish`로 표시한다.
- `BranchRideSwitch`: 수액 명중 누적, 연속 분사 재무장, 여러 분기기 피벗의 A/B 자세 표시. 직렬화 호환성을 위해 `_disconnectedEuler`는 A 자세, `_connectedEuler`는 B 자세 필드로 유지한다.
- `BranchRideStone`: 결정적인 낙하/구르기/추락/재생성 궤적.
- `BranchRidePresentation`: 최초 이동/과녁/회전/돌 안내 대사. 게임 판정에 관여하지 않는다.

Host만 게임 상태를 진행하고 Fusion으로 구간, 이동 거리, 부적 위치/방향, 가지 상태와 회전 진행률, 돌 시계, 탑승 마스크, 실패 횟수, 정지 상태를 복제한다. 실제 탑승자는 기존 `NetworkPlayer.SetTransportAuthoritatively`를 사용한다. 스테이지 전환 시 복용한 능력은 기존 스냅샷에서 유지하며, 이 스테이지에서 캐릭터별로 재할당하지 않는다.

기존 직렬화 필드와 SFX 참조용 `_talisman`, `_stones` 및 표시 프로퍼티를 유지했다. 전역 입력/이동에 새 키 확인은 추가하지 않았다. 공용 잎 입력에서 빠져 있던 좌클릭 회수만 기존 Use 액션의 시퀀스로 연결했다.

## 오프라인 확인

씬에는 두 개의 오프라인 캐릭터와 기존 `OfflinePossessionController`를 배치했다. 시작 테스트 능력은 슬롯 0 수액, 슬롯 1 나뭇잎이다. 기존 `OfflinePossessOther` 액션(기본 F)으로 제어 대상을 바꾸고 각각 E로 탑승할 수 있다. 네트워크 세션에서는 `PlayerSpawnLayout`이 두 오프라인 캐릭터를 비활성화한다. 임시 어댑터를 제거해도 Photon의 두 명 탑승 조건은 그대로다.
